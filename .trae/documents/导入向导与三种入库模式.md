# 导入向导 + 三种入库模式（链接 / 复制 / 移动）

## 摘要（Summary）

把工具栏上的「导入文件」「导入文件夹」两个入口合并为一个「导入…」按钮，点击后弹出单页导入向导：

1. 在向导里添加 ROM 文件或文件夹（可混选、可拖放），自动扫描出待导入列表；
2. 列表内可编辑标题、平台，可批量指定平台；
3. 选择入库方式：**仅链接**（只记录路径）/ **复制到库目录** / **移动到库目录**；
4. 点「开始导入」执行，完成后回到主界面并显示统计。

## 方案（Proposed Changes）

### 1. 新增 `Models/ImportMode.cs`

```csharp
public enum ImportMode { Link, Copy, Move }
```

同时在此文件放 `public sealed class ImportWizardResult`
（`List<ImportCandidate> Candidates`、`ImportMode Mode`），供向导返回。

### 2. 新建 `Views/ImportWizardWindow.xaml` + `.xaml.cs`

单页布局（Width≈760 / Height≈620，`WindowStartupLocation=CenterOwner`），自上而下：

- **来源区**：`ListBox`（显示添加的文件/文件夹路径，可多选）+ 按钮「添加文件…」「添加文件夹…」「移除选中」「清空」。
  - 支持拖放：`AllowDrop=true`，`Drop` 事件把文件/目录加入来源列表。
- **扫描区**：`DataGrid`（列：文件名 / 标题 / 平台 / 大小，标题与平台可编辑；平台列用 `ComboBox`，选项 = `PlatformCatalog.Common` + 已发现平台），上方显示 `共 N 个文件，其中 M 个需要指定平台，重复 K 个`；右侧「全部设为平台」输入 + 应用按钮。
- **入库方式区**：三个 `RadioButton`：
  - 「仅链接：只记录路径，不动文件」
  - 「复制到库目录」（显示库目录路径；为空时该项禁用并提示去设置）
  - 「移动到库目录」（同上）
  - 附带勾选框「包含子文件夹中的 ROM」（递归，默认 true）。
- **底部**：「取消」`IsCancel`，「开始导入」`PrimaryButtonStyle`（等价 `IsDefault`）。
- 行为：
  - 添加来源后自动扫描（`Task.Run(RomImporter.Scan)`，`existingPaths` 由主界面传入）。
  - 「开始导入」前校验：候选数 > 0、标题/平台非空、复制/移动模式必须已配置库目录；校验失败用 `MessageBox` 提示，不关闭。
  - 成功则 `DialogResult = true`，并暴露 `Result`（候选 + 模式）。
  - 扫描/导入期间禁用按钮，防重复点击。

### 3. `Services/RomImporter.cs` 扩展

- 抽出 `ResolveTargetPath(sourceFile, libraryRoot, platform)`（现 `CopyToLibrary` 内生成目标路径并与同名冲突处理的逻辑），供复制与移动共用。
- 新增 `MoveToLibrary(sourceFile, libraryRoot, platform)`：`Directory.CreateDirectory` → 计算目标 → `File.Move(target same disk)`；跨盘 `IOException` 时退化为 `File.Copy + File.Delete`；源文件缺失抛异常由调用方计入失败。
- `CopyToLibrary` 改为调用 `ResolveTargetPath`，行为与现在一致（保证兼容）。

### 4. `ViewModels/MainViewModel.cs`

- 删除 `ImportFilesAsync`、`ImportFolderAsync` 两个 `[RelayCommand]`。
- 新增单个命令：

```csharp
[RelayCommand]
private async Task ImportAsync()   // 无参版本，弹向导
```

- 新流程：构造 `ImportWizardWindow(existingPaths, libraryRoot, defaultMode)` → `ShowDialog()`；取消则 `StatusMessage="已取消导入"`。
- 按 `Result.Mode` 逐项处理：
  - `Link` → `romPath = candidate.FilePath`
  - `Copy` → `RomImporter.CopyToLibrary(...)`
  - `Move` → `RomImporter.MoveToLibrary(...)`
  - 之后 `new Game { Title, Platform, RomPath, FileSize, Status=NotPlayed }` → `Insert` → `Games.Add`。
- 统计沿用现有文案（新增 / 跳过重复 / 失败）。
- 拖放：`ImportAsync(IEnumerable<string> inputs, bool recursive)` 改为**带初始来源**的重载，内部同样弹向导（把本次拖入的路径预置到来源列表），不再直接扫描入库。
- 入库模式的默认值：从设置读 `library.import_mode`（"link"/"copy"/"move"），无则回退旧键 `library.copy_on_import`（true→copy，false→link）。

### 5. `MainWindow.xaml` / `.xaml.cs`

- 两个按钮合并为一个：

```xml
<Button Command="{Binding ImportCommand}" ...>导入…</Button>
```

- `OnDrop` 改为 `await _viewModel.ImportAsync(paths, true)`（与上面的新重载匹配）。

### 6. `Views/SettingsWindow.xaml` + `.xaml.cs`

- 「导入策略」下拉改为三项：仅链接 / 复制到库目录 / 移动到库目录。
- 保存时写 `library.import_mode`（字符串枚举名小写），并同步写旧键 `library.copy_on_import`（copy→true，其余 false）以兼容。
- 读取时优先 `library.import_mode`，否则按旧键推断。
- 「库目录」行保持不变；为空时在向导中提示到设置里配置。

### 7. `Views/ImportPreviewWindow.*`

- 不再被引用（向导内的列表已覆盖预览编辑功能）。按项目规则不删除文件：保留原文件，仅在计划备注中标记为「已弃用，后续清理」。CSProj 无需改动。

## 决策与假设（Assumptions & Decisions）

- **单页向导**，不做多步分页（需求描述为一次添加、一次选择模式）。
- **沿用现有库目录设置与按平台分目录的存放规则**（`库目录/<平台>/文件名`），移动与复制共用。
- **链接模式不做路径规范化之外的任何操作**，与当前「仅索引」行为一致。
- **移动失败时不做回滚**：单条失败计入「失败 N 条」，其余继续；源文件不存在的条目直接失败。
- **向导允许重复来源**：扫描层已按全路径去重，重复计入「重复 K 个」。
- **不新增数据库字段**：入库方式不落库（链接/复制/移动只是写入时的一次性动作）。
