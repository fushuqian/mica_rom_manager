# 模拟器相对路径 + 平台管理

## 摘要（Summary）

1. **模拟器位置改相对存储**：新增 `%DATA%` 占位符方案——凡位于数据目录（`publish\data`）之下的路径（安装目录、exe、核心、配置）统一存为 `%DATA%\emulators\PCSX2\pcsx2.exe` 形式，启动时按实际数据目录展开。老库中的绝对路径在启动时一次性规范化为相对形式，读取端同时兼容绝对路径与 `%DATA%` 前缀。
2. **新增平台管理**：新增 `platforms` 表，记录每个平台的默认模拟器与库内子文件夹；解析模拟器时优先用平台默认，导入复制/移动时按平台的子文件夹归档。UI 放在设置窗口新增的「平台」页。

## 方案（Proposed Changes）

### 1. 新增 `Services/LocalPath.cs`

```csharp
public static class LocalPath
{
    public const string DataToken = "%DATA%";
    public static string ToStored(string absolute);      // DataDir 下 → %DATA%\xxx，否则原样
    public static string Expand(string stored);          // %DATA% 前缀 → 实际绝对路径
    public static bool IsUnderDataDir(string absolute);
}
```
- 基准目录取 `AppServices.Paths.DataDir`（`LocalPath` 内部通过 `AppServices.Paths` 访问，避免重复构造 PathService）。
- 比较时统一 `Path.GetFullPath` + 大小写不敏感，并确保路径边界（`DataDir\` 前缀），防止 `data2` 误判。

### 2. `EmulatorPaths.Resolve` 支持 `%DATA%`

[EmulatorResolver.cs](file:///d:/Trae/MICA_ROM_MANAGER/src/MicaRomManager/Services/EmulatorResolver.cs#L15-L32)：先 `LocalPath.Expand(value)`，之后按现有规则（绝对路径原样 / 相对路径拼 `installDir`，`installDir` 也先展开）解析。

### 3. 写入端统一转相对

- [EmulatorEditViewModel.cs](file:///d:/Trae/MICA_ROM_MANAGER/src/MicaRomManager/ViewModels/EmulatorEditViewModel.cs)：
  - `BrowseInstallDir` → `Model.InstallDir = LocalPath.ToStored(dialog.FolderName)`；
  - `ToRelative` 优先 `LocalPath.ToStored`，其次退回「相对 InstallDir」的现有逻辑（保留非 data 目录下的模拟器可移植性）。
- [EmulatorManagerViewModel.cs](file:///d:/Trae/MICA_ROM_MANAGER/src/MicaRomManager/ViewModels/EmulatorManagerViewModel.cs#L148-L161)：安装完成时 `InstallDir = LocalPath.ToStored(result.InstallDir)`；`ExePath` 仍存相对 InstallDir 的相对路径（因为 InstallDir 已相对化，两者可一起搬移）。

## 决策与假设（Assumptions & Decisions）

- **相对路径基准是数据目录**（`PathService.DataDir`），用 `%DATA%` 显式标记，避免与「相对 InstallDir」的既有语义混淆。
- **不做 SQL 层批量替换**，改由 C# `NormalizePaths()` 在启动时规范化，便于处理 `DBNull`、大小写与跨盘路径异常。
- **平台配置不覆盖游戏自身绑定**：游戏若已指定 `EmulatorId`，仍以游戏为准。
- **平台表预置 `PlatformCatalog.Common` 全部平台**，folder 默认同名；用户可自行改名或添加自定义平台。
- **新增/未识别的平台**在导入时自动补一行平台配置（folder=平台名），不弹窗打扰。
- **`emulator_platforms.is_default` 保留**，作为平台默认的兼容兜底，避免破坏现有模拟器编辑窗口「设为默认」的行为。
- 平台管理不做独立窗口，直接放设置页（与现有「区域 / 语言」页风格一致）。
