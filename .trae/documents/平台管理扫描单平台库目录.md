# 平台管理：扫描单平台库目录

## 摘要（Summary）

在「设置 → 平台」页为当前选中的平台增加一个「扫描该平台库目录…」按钮：

- 只扫描 `库目录\<该平台子文件夹>\`（子文件夹取平台管理的配置，未配置则用平台名），不扫描整库；
- 把目录里尚未入库的 ROM 补进库——对应用途：手工拷进库的 ROM、从库中移除但文件没删的 ROM；
- 复用现有导入预览窗口确认（可改标题/平台），确认后以「链接」方式入库（文件已在库目录，不再复制/移动）。

### 2. `SettingsWindow.xaml.cs`：新增扫描与入库逻辑

```csharp
private void ScanPlatformLibrary_Click(object sender, RoutedEventArgs e)
```

流程：

1. 校验：未选中平台 → 提示「请先选择平台」。
2. 取库目录 `AppServices.Settings.Get("library.root")`，为空 → 提示「请先在常规设置里配置库目录」。
3. 计算目标目录：
   `var folderName = string.IsNullOrWhiteSpace(setting.Folder) ? setting.Name : setting.Folder;`
   `var dir = Path.Combine(libraryRoot, RomImporter.SanitizeFolderName(folderName));`
   目录不存在 → 提示「该平台库目录不存在：{dir}」，结束。
4. `var existing = AppServices.GameRepo.ListAll().Select(g => g.RomPath).ToList();`
   `var scan = RomImporter.Scan(new[] { dir }, recursive: true, existing);`
5. 候选为 0 → 提示「该平台库里没有需要补充的 ROM（重复 {DuplicateCount} 个，忽略 {ExcludedCount} 个）」。
6. 将每个候选 `Platform` 预设为当前平台：`foreach (var c in scan.Candidates) c.Platform = setting.Name;`
7. 弹出已有的 `ImportPreviewWindow(scan.Candidates)`（`Owner = this`）；取消则返回。
8. 确认后逐条入库（链接语义，不动文件）：

```csharp
foreach (var candidate in scan.Candidates)
{
    try
    {
        AppServices.GameRepo.Insert(new Game
        {
            Title = candidate.Title.Trim(),
            Platform = candidate.Platform,
            RomPath = candidate.FilePath,
            FileSize = candidate.FileSize,
            Status = GameStatus.NotPlayed,
        });
        added++;
    }
    catch { failed++; }
}
```

9. MessageBox 汇总：「已从该平台库补充 N 条」+（失败 M 条时追加）。

### 4. 不使用/不修改的部分

- 不复用导入向导（`ImportWizardWindow`）：它用于「选择来源 + 入库方式」，此处来源固定为平台库目录、方式固定为链接，直接用预览窗口更贴合。
- 不新增数据库字段或表：纯扫描 + 新增记录。

## 决策与假设（Assumptions & Decisions）

- **扫描范围**：仅 `库目录\<平台子文件夹>`，递归子目录（库内可能按字母/分类再分层）。
- **归档方式固定为链接**：文件本来就在库目录内，复制/移动无意义。
- **平台固定为当前选中平台**，预览窗口里仍可手工改（改后按改后的平台入库）。
- **去重依据全路径**（`RomImporter.Scan` 的既有逻辑，大小写不敏感）；不做按标题去重，避免误伤同名不同版本。
- **失败不中断**：逐条 try/catch，最后汇总失败数。
- **扫描前不要求先保存平台设置**：使用列表当前行的内存值（`PlatformSetting` 对象），因此改了子文件夹还没点保存也能正确扫描。

## 验证（Verification）

1. `dotnet build MicaRomManager.sln -c Release`：0 警告 0 错误；`dotnet test`：48 用例全通过。
2. 手工（从 publish 启动）：
   - 设置 → 平台选 PS2，库目录已配置；向 `库目录\PS2\` 手工拷入 1 个 ISO；
   - 点「扫描该平台库目录…」→ 预览出现该 ISO，平台已是 PS2 → 确认；
   - 主界面出现该条目，路径指向库内文件，文件未被移动；
   - 再扫一次 → 提示「没有需要补充的 ROM（重复 1 个）」；
   - 从库中移除某 PS2 条目（不删文件）→ 再扫描 → 该 ROM 重新出现；
   - 扫描 NES 平台目录时，PS2 目录里的文件不会被带入；
   - 未配置库目录时点扫描 → 给出配置提示，不报错。
