# 子库整理、失效清理与指纹列

## 摘要

1. **列表展示指纹**：把主界面最后的「文件路径」列换成「指纹」列，显示 `RomHash` 并支持排序，用于筛查「文件名不同但内容相同」的重复条目。
2. **扫描时清理失效条目**：平台管理里扫描某平台子库时，顺带删除该平台中文件确实不存在的记录；子库内条目直接删，链接入库的记录先到原路径确认（`File.Exists`）再删。
3. **子库整理按钮**：平台管理新增「整理该平台库文件…」，把该平台子库目录内的 ROM 文件按 `{标题} Disc-{碟号} ({区域})({语言}).{扩展名}` 重命名（仅多碟写碟号），成功后同步数据库路径。

### 2. 新建 `src/MicaRomManager/Services/LibraryOrganizer.cs`

公开 API：

```csharp
public sealed record OrganizeResult(int Renamed, int Skipped, int Failed, List<string> FailedFiles);

public static class LibraryOrganizer
{
    public static string BuildFileName(Game game, int discIndex, string sourcePath);
    public static int RemoveMissing(GameRepository repo, IEnumerable<Game> games);
    public static OrganizeResult Organize(GameRepository repo, IEnumerable<Game> games, string platformDir);
    public static bool IsUnderDirectory(string path, string directory);
}
```

**`BuildFileName` 规则（仅多碟写碟号）**

- 标题：`game.Title` 去除两端空白；非法字符（`Path.GetInvalidFileNameChars()`）替换为 `_`；连续空白折叠成一个空格；`TrimEnd('.')`；为空返回 `""`（调用方跳过）。标题超过 150 字符时截断，避免超长文件名。
- 碟号：仅当 `game.Discs.Count > 1` 时追加 ` Disc-{discIndex + 1}`（`discIndex` 是该碟在 `Discs` 中的下标）。
- 区域/语言：各自非空才输出。格式为 ` ({区域})({语言})`——第一个括号前加空格，两个括号相邻；只有其一时只输出一个括号。
- 多值：`Region`/`Language` 按 `,` `，` `、` 拆分后去空、去重，用英文逗号连接，如 `(简体中文,英语)`。
- 扩展名：沿用该碟原扩展名 `Path.GetExtension(sourcePath)`。
- 示例：`新鬼武者 Disc-1 (欧版)(英语).chd`；单碟 `新鬼武者 (欧版)(英语).chd`；无区域语言 `新鬼武者 Disc-1.chd`。

**`RemoveMissing`**

- 只处理传入的 `games`（调用方已按当前平台过滤）。
- `RomPath` 为空的记录**不删**（避免误删待补路径的条目）。
- `game.Discs` 全部不存在 → `repo.Delete(game.Id)` 并计数；任意一张碟存在则保留（多碟部分缺失不整条删除）。

**`Organize`**

- 逐条处理；对每张碟：
  - 跳过 `!File.Exists` 的碟；
  - 跳过不在 `platformDir` 下的碟（`Path.GetFullPath` 前缀比较、忽略大小写）——链接入库的文件不改名；
  - 生成目标文件名，目标与当前路径相同 → 视为跳过；
  - 目标已存在且不是自身 → 追加 ` (2)`、` (3)`… 到扩展名前；
  - `File.Move(source, target)`；异常计入 `Failed` 并继续后续文件。
- 一条记录至少改了一个碟片后，更新 `game.RomPath`（第一碟，若被改）与 `game.DiscPaths`（其余碟，换行分隔），再 `repo.Update(game)`；`RomHash` 保持原值。
- 无任何碟可处理 → `Skipped++`。

## 决策与假设

- **「路径改成 hash」= 仅列表展示**：数据库与文件命名都不变，`rom_path` 仍是真实路径；老板已确认目的是排序筛查 hash 相同但文件名不同的条目。
- **单碟不写碟号**：`新鬼武者 (欧版)(英语).chd`；老板已确认「仅多碟写碟号」。
- **区域/语言为空则省略括号**；多值用英文逗号连接（老板未另行指定，按推荐方案）。
- **整理只动子库目录内的文件**：链接入库（路径在库外）的 ROM 不改名，避免破坏用户原目录；这类记录仍会正常参与扫描与清理。
- **清理不弹确认**：范围限定当前平台，子库内缺失直接删；链接记录以原路径 `File.Exists` 为准，无 `RomPath` 的记录不删。
- **不改数据库结构**：`rom_hash` 列已在 v6 存在，无需迁移。
