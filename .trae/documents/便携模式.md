# 便携模式（相对路径）

## 摘要

设置 → 常规新增「便携模式」开关。固定布局：程序 exe 放在移动硬盘根目录，ROM 库是同级的任意命名文件夹（例如 `E:\MicaRomManager.exe` + `E:\game_library\`，库目录名不限定为 `Roms`）。开启后，库目录、ROM / 多碟 / 封面路径、模拟器路径都以「程序所在目录」为基准保存为相对路径，换电脑盘符变化也能直接使用。

便携模式开启时，每次启动都会检查库目录；找不到时弹窗让用户「重新指定库目录（自动把旧记录对到新位置）」或「放弃旧库并新建（清空游戏库，模拟器与设置保留）」。

## 存储效果示例

| 字段 | 便携模式关闭 | 便携模式开启 |
| --- | --- | --- |
| `settings.library.root` | `E:\game_library` | `game_library` |
| `games.rom_path` | `E:\game_library\PS2\新鬼武者.chd` | `game_library\PS2\新鬼武者.chd` |
| `games.disc_paths` | `E:\game_library\PS2\新鬼武者 Disc-2.chd` | `game_library\PS2\新鬼武者 Disc-2.chd` |
| `games.cover_path` | `E:\data\covers\a.png` | `data\covers\a.png` |
| `emulators.exe_path` | `E:\data\emulators\PCSX2\pcsx2.exe` | `%DATA%\emulators\PCSX2\pcsx2.exe` |

读取时统一展开为当前盘符的绝对路径，启动游戏、缺失判断、扫描去重逻辑不需要改。

## 现状分析

- `library.root` 目前直接存绝对路径，读取点共 4 处：[SettingsWindow.xaml.cs](file:///d:/Trae/MICA_ROM_MANAGER/src/MicaRomManager/Views/SettingsWindow.xaml.cs#L37)（显示）、扫描（#L172）、整理（#L277），以及 [MainViewModel.cs](file:///d:/Trae/MICA_ROM_MANAGER/src/MicaRomManager/ViewModels/MainViewModel.cs#L210)（导入向导）。
- 子库目录（`library.root + platform.folder`）实时计算，`platforms.folder` 只存文件夹名，会随库目录自动跟随。
- `games.rom_path`、`disc_paths`、`cover_path` 目前是绝对路径写库，便携模式下需要转相对。
- 模拟器路径只有位于 `data\` 下才转成 `%DATA%`，装在程序目录其它位置时仍是绝对路径，需要一并纳入。
- 数据库、covers/emulators/downloads 等目录由 `AppContext.BaseDirectory` 运行时计算，不落库，无需改动。
- 分享包 bat、CSV、数据库备份/恢复的路径属于导出物或临时选择，不在便携范围内。

## 改动清单

### 1. 新建 `src/MicaRomManager/Services/PortablePath.cs`

```csharp
public static class PortablePath
{
    public const string SettingKey = "library.portable";

    public static bool Enabled => AppServices.Settings?.GetBool(SettingKey) == true;

    public static string Expand(string stored);
    public static string Expand(string stored, string baseDir);
    public static string ToStored(string absolutePath);
    public static string ToStored(string absolutePath, bool portable);
    public static string ToStored(string absolutePath, bool portable, string baseDir);
    public static string ExpandMultiLine(string stored);
    public static string ToStoredMultiLine(string stored, bool portable);
    private static string ToRelative(string absolutePath, string baseDir);
}
```

规则：

- `Expand`：空值返回空；先 `LocalPath.Expand`（兼容 `%DATA%`）；结果若仍是绝对路径则原样返回，否则基于 `baseDir` 拼成绝对路径。
- `ToStored(absolute, portable)`：先 `LocalPath.ToStored`（`data\` 下得到 `%DATA%`）；若仍是绝对且 `portable == true` → 相对路径；否则保持绝对。
- `ToRelative`：`Path.GetRelativePath(baseDir, full)`；返回绝对（跨盘等异常）时原样返回，不报错。
- 多行版本按 `\n` 拆分逐行转换。

### 2. `src/MicaRomManager/Data/GameRepository.cs`

- `Map(reader)`：`RomPath`、`DiscPaths`、`CoverPath` 全部经 `PortablePath` 展开，内存中的 `Game` 永远持有绝对路径。
- `AddParameters`：三个路径字段用 `PortablePath.ToStored` 写库（按 `Enabled`）。
- 新增 `public int NormalizePaths(bool portable)`：`ListAll()` 后逐条 `UPDATE games SET rom_path/disc_paths/cover_path`，值为 `PortablePath.ToStored(x, portable)`，返回处理条数。
- 新增 `public int RelocateLibraryPaths(string oldRoot, string newRoot)`：
  - 遍历所有记录；对 `RomPath` 与 `DiscPaths` 每一行：
    - 仅当路径位于 `oldRoot` 下、`File.Exists(旧路径)` 为 false、`File.Exists(newRoot\相对子路径)` 为 true 时，替换为新绝对路径；
    - 其余（旧文件仍在、或新位置没有对应文件）保持不变。
  - 封面：`CoverPath` 文件不存在时，取文件名在 `AppServices.Paths.CoversDir` 下查找，存在则替换。
  - 逐条更新 `rom_path/disc_paths/cover_path`（存值经 `PortablePath.ToStored`），返回发生重定位的记录数。
- 新增 `public void DeleteAll()`：`DELETE FROM games;`（仅游戏库，模拟器/平台/词典/设置保留）。

## 决策与假设

- 便携模式固定布局：exe 与库文件夹同级；库目录名由用户指定（如 `game_library`、`Roms`），程序不写死默认名。
- 相对基准为程序所在目录；范围包含库目录、ROM/多碟、封面、模拟器路径。
- 便携模式开启时每次启动检查库目录；库目录为空或不存在都会弹窗（老板确认）。
- 重新指定库目录时，按「旧库目录 → 新库目录」自动重定位：只改「旧文件不在、新位置有同名同相对路径文件」的记录；封面按文件名在新 `data\covers` 下找回。
- 「放弃旧库并新建」= 用户选新文件夹 + 二次确认后清空 `games` 表，模拟器/平台/词典/设置保留。
- 保存开关时立即把存量记录统一转为相对（取消时转回绝对）。
- 不改数据库结构，不需要迁移。
