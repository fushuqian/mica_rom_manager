# 批量编辑

## 摘要

为游戏列表增加批量编辑：选中多行后，通过工具栏「批量编辑」或右键菜单打开弹窗，勾选要修改的字段并填写新值，只影响已勾选的字段。支持平台、类型、区域、语言、年份、发行商、开发商、状态、模拟器、标签（追加/移除）、备注（追加/覆盖）。

## 改动清单

### 1. 新建 `src/MicaRomManager/Models/BatchEditChanges.cs`

纯数据 + 应用逻辑，便于单元测试：

```csharp
public sealed class BatchEditChanges
{
    public bool ApplyPlatform; public string Platform = "";
    public bool ApplyGenre; public string Genre = "";
    public bool ApplyRegion; public string Region = "";
    public bool ApplyLanguage; public string Language = "";
    public bool ApplyReleaseYear; public int? ReleaseYear;
    public bool ApplyPublisher; public string Publisher = "";
    public bool ApplyDeveloper; public string Developer = "";
    public bool ApplyStatus; public string Status = "";
    public bool ApplyEmulator; public long? EmulatorId;
    public bool ApplyTagsAdd; public string TagsAdd = "";
    public bool ApplyTagsRemove; public string TagsRemove = "";
    public bool ApplyNotes; public bool NotesAppend; public string Notes = "";

    public void ApplyTo(Game game);
}
```

`ApplyTo` 规则：

- 每个字段仅当对应 `ApplyXxx` 为 true 时写入，未勾选一律不动。
- 文本字段直接赋值（勾选后留空 = 清空该字段；平台除外，见校验）。
- 标签：先把 `TagsAdd`、`TagsRemove` 各自按 `,` `，` `;` `；` 拆分、去空、去重（忽略大小写）；
  - 追加：原标签中不存在才加入；
  - 移除：把原标签中同名项删除（在追加之后执行，即同名时最终为移除）；
  - 任一标签开关勾选时，最终用 `,` 重新拼接写回 `game.Tags`。
- 备注：`NotesAppend == true` 时，原备注非空则 `原备注 + Environment.NewLine + Notes`，为空则直接写入；`NotesAppend == false` 时直接覆盖。
- 模拟器：写入 `game.EmulatorId = EmulatorId`（`null` 表示清除绑定）。

### 2. 新建 `src/MicaRomManager/ViewModels/BatchEditViewModel.cs`

`ObservableObject`，构造函数只接收 `int selectedCount`，内部自行取数（与 `GameEditViewModel` 一致）：

- 集合：`Platforms`（`PlatformCatalog.Common` + 库内已有平台）、`Regions`、`Languages`（取自 `LookupRepository`）、`Statuses`（`GameStatus.All`）、`EmulatorChoices`。
- `EmulatorChoices`：`record EmulatorChoice(long? Id, string Name)`，第一项 `(null, "（不指定）")`，其后为启用的模拟器。
- 每个字段一组属性：`[ObservableProperty] bool applyPlatform;` + `[ObservableProperty] string platformValue = "";` … 依此类推；模拟器为 `EmulatorChoice? selectedEmulator`；年份为字符串 `releaseYearText`；备注有 `notesAppend = true`（默认追加）与 `notesValue`。
- `[ObservableProperty] string error = "";`
- `BatchEditChanges? BuildChanges()`：
  - 统一修剪字符串；
  - 勾选了「平台」但值为空 → `Error = "平台不能为空"`，返回 null；
  - 勾选了「年份」且文本非空时必须解析为 `int`（范围 1950–2100）→ 否则 `Error = "年份格式不正确"`，返回 null；
  - 勾选了备注但文本为空且为追加模式 → 允许（相当于不追加）；
  - 一个字段都没勾选 → `Error = "请至少勾选一个要修改的字段"`，返回 null。

### 4. `src/MicaRomManager/ViewModels/MainViewModel.cs`：新增命令

```csharp
[RelayCommand]
private void BatchEdit()
{
    var games = SelectedGames.ToList();
    if (games.Count == 0)
    {
        MessageBox.Show("请先在列表中选中要批量编辑的游戏（可按住 Ctrl / Shift 多选）。",
            "批量编辑", MessageBoxButton.OK, MessageBoxImage.Information);
        return;
    }

    var window = new BatchEditWindow(games.Count) { Owner = Application.Current?.MainWindow };
    if (window.ShowDialog() != true || window.Changes == null) return;

    foreach (var game in games)
    {
        window.Changes.ApplyTo(game);
        AppServices.GameRepo.Update(game);
    }

    RefreshLookups();
    ApplyFilter();
    StatusMessage = $"已批量更新 {games.Count} 条";
}
```

## 决策与假设

- **只改已勾选字段**：老板已确认；弹窗默认全部不勾选，输入控件在勾选后才启用。
- **标签追加 + 移除**：老板已确认；先追加后移除，同名最终被移除；其余标签原样保留。
- **备注默认追加**，可切换到覆盖（批量覆盖容易丢信息，追加更安全）。
- **平台不允许批量清空**（勾选后必须填值）；其他文本字段勾选后留空即清空。
- **不做异步**：与现有 `ToggleFavorite` 一致，逐条 `GameRepo.Update`；几百条量级可接受。
- **入口不做权限/状态限制**：未选中时点按钮弹提示，不置灰。
- 不引入新的数据库字段，无需迁移。
