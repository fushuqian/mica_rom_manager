# M2 盘符设备发送 + 模块化设备配置（v0.16.0）实施计划

## 摘要

新增「发送到设备…」：把选中游戏的全部碟片按原文件名复制到 U 盘 / 掌机存储，支持空间校验、同名跳过/覆盖、逐文件进度与结果汇总；只读源文件，不改数据库。

同时引入模块化「设备配置」：设备类型（传输方式 + 品牌/型号）、目录结构（根目录 + 模板 + 平台目录别名）全部写进配置文件。内置一套默认配置，用户可把自定义 JSON 放到 `data\devices\`，也可在设置里新增/编辑。盘符设备本轮启用，MTP 传输方式先保留配置、界面标记暂不支持。

## 设备配置模型与 JSON

### 新增 `src/MicaRomManager/Models/DeviceProfile.cs`

```csharp
public sealed class DeviceProfile
{
    public string Id { get; set; } = "";              // 唯一标识，保存时生成
    public string Name { get; set; } = "";            // 显示名，如「Anbernic RG 系列」
    public string Brand { get; set; } = "";           // 品牌，如 Anbernic
    public string Model { get; set; } = "";           // 型号，如 RG35XX
    public string Transport { get; set; } = "drive";  // drive = 盘符设备；mtp = 安卓 MTP（预留）
    public string RootFolder { get; set; } = "Roms";  // 盘内根目录
    public string FolderTemplate { get; set; } = "{root}/{platform}";
    public Dictionary<string, string> PlatformFolders { get; set; } = new(); // 平台 → 目录别名
    public string Notes { get; set; } = "";

    public bool IsDrive => Transport == "drive";

    public string Display
    {
        get
        {
            var maker = $"{Brand} {Model}".Trim();
            return string.IsNullOrWhiteSpace(maker) ? Name : $"{Name}（{maker}）";
        }
    }
}
```

`FolderTemplate` 支持占位符：`{root}`、`{platform}`、`{title}`、`{year}`。默认 `{root}/{platform}`；想让每游戏一个文件夹就写 `{root}/{platform}/{title}`。文件名始终原样，不重命名。

### 内置 `src/MicaRomManager/Resources/DeviceProfiles.json`（数组）

0. `trimui-smart-pro`（实机配置）：`drive`，根 `Roms`，模板 `{root}/{platform}`，`allowUnmappedPlatforms=false`。依据 F:\（TrimUI Smart Pro SD 卡）实机 `Emus/*/config.json` 的 `rompath` / `extlist` 与 `Roms/*` 目录确认，映射：FC→FC、SFC→SFC、GB/GBC/GBA/NDS/N64、MD/MS/GG、SS/DC、PS/PSP、PCE、WS/WSC、NEOGEO/NGP、ATARI2600/7800/LYNX、ARCADE/CPS1-3/FBNEO/MAME/MAME2003PLUS/MAME2010/PGM、GW、DOS、PICO8、JAVA、OPENBOR、EASYRPG。`PSBIOS`（BIOS）与 `FFMPEG`（播放器）不映射。
1. `generic-drive`：通用 U 盘 / 掌机，`drive`，根 `Roms`，模板 `{root}/{platform}`，无别名。
2. `android-mtp`：安卓掌机（MTP 预留），`mtp`，根 `roms`，模板 `{root}/{platform}`，备注「MTP 传输暂未支持，仅保存结构配置」。

具体每台设备的目录规则后续确认时，直接在应用内编辑或改 JSON，不需要再改代码。

### 新增 `src/MicaRomManager/Services/Devices/DeviceProfileStore.cs`

- 构造：`DeviceProfileStore(string userDir, string builtinFile)`，便于单测；AppServices 用 `Paths.DevicesDir` 与 `Resources\DeviceProfiles.json`。
- `Load()`：内置数组 + 用户目录每个 `*.json`（单个对象；兼容数组）；按 `Id` 合并，用户配置覆盖同 Id 内置。
- `Save(DeviceProfile)`：写 `userDir\{id}.json`（单对象）；Id 为空时按名称生成 slug，冲突时追加序号；内置配置保存即生成同 Id 的用户覆盖文件。
- `Delete(DeviceProfile)`：只删用户目录文件；内置无覆盖时提示「内置配置不能删除，可复制后修改」。
- `IsBuiltIn(profile)` 标记来自内置且未被覆盖。

### 新增 `src/MicaRomManager/Services/Devices/SendPathBuilder.cs`

- `ResolveFolder(profile, driveRoot, game)`：
  - 按 `/` 与 `\` 切分模板，逐段替换 `{root}`、`{platform}`、`{title}`、`{year}`；
  - `{root}` → `driveRoot` + `RootFolder`；`{platform}` → `PlatformFolders` 命中值，否则平台原名；`{title}`/`{year}` → 游戏标题/年份（年份为空时跳过该段）；
  - 每一段用 `SharePackager.SanitizeName` 清洗，空段跳过，最后 `Path.Combine`；
  - `Path.GetFullPath` 结果必须仍在 `driveRoot` 之下，否则抛 `InvalidOperationException`（避免 `..` 跳盘）。
- `ResolveTargetFile(profile, driveRoot, game, sourcePath)`：目录 + 原文件名。

### 新增 `src/MicaRomManager/Services/Sending/DriveSendTarget.cs`

- `Send(files, profile, driveRoot, policy, progress, token)`：
  - 逐文件：源缺失 → 失败 + 警告；目标存在且 Skip → 跳过；否则建目录 + `File.Copy(..., overwrite)`；
  - 单文件异常只记警告，不中断整批；每文件回调 `SendProgress`；
  - `TargetRoot` 返回本次使用的根目录，供「打开目标目录」。
- 只读源文件，不移动、不删除。

### 新增 `src/MicaRomManager/ViewModels/DeviceSendViewModel.cs`

- 行模型 `DeviceSendRow`（Title / Platform / FileName / SizeText / Note）。
- 构造接收选中游戏：展开 `game.Discs`；缺失文件标「文件缺失」且不参与发送；统计游戏数/文件数/总字节。
- 属性：

  - `Conflict`（跳过/覆盖，默认跳过）、`EstimateText`、`SpaceText`（空间不足红色提示）、`TargetPreview`（`E:\Roms\psx`）；

  - `OpenTargetCommand`：打开 `LastTargetRoot`。
- 配置或盘变化时重算 `TargetPreview` / `SpaceText`。

## 假设与决策

- 「设备类型」同时包含传输方式（drive/mtp）与品牌/型号；本轮只发送到盘符设备，MTP 仅保存配置并在界面标注暂不支持。
- 目录规则：根目录 + 模板 + 平台别名；文件名不改。具体设备目录值后续确认后通过应用内编辑或 JSON 调整，无需改代码。
- 配置来源：内置 `Resources\DeviceProfiles.json` + 用户 `data\devices\*.json`；同 Id 用户覆盖内置；内置配置不能直接删，保存即生成覆盖文件。
- 多碟游戏全部碟片发送，缺失碟片跳过并提示。
- 不改数据库、不记录发送历史、不改库路径与状态。
- 进度为文件级（与分享打包一致）；本版不做取消按钮与自动弹出设备。
- 版本号 `0.16.0`（对应 ROADMAP M2）；M1 文件名刮削后续单独排期。
